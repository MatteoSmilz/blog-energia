# Contributing

[English](#english) | [Italiano](#italiano)

## English

Thanks for your interest in *Le centrali della natura*! This blog is an individual school project: texts, simulations and code must be written by me, so **I cannot accept pull requests** or contributions of code or content.

Reports through [issues](../../issues) are very welcome:

- scientific errors or inaccuracies in the articles
- calculation or unit errors
- bugs in the simulations or the website
- broken links or missing credits

Please describe the problem and, if possible, point to the page and a source. I will make the fixes myself and reference your report in the commit.

Pull requests will be closed with a link to this file. Nothing personal!

## Italiano

Grazie dell'interesse per *Le centrali della natura*! Questo blog è un lavoro scolastico individuale: testi, simulazioni e codice devono essere realizzati da me, quindi **non posso accettare pull request** né contributi di codice o contenuti.

Le segnalazioni tramite le [issue](../../issues) sono molto apprezzate:

- errori scientifici o imprecisioni negli articoli
- errori di calcolo o nelle unità di misura
- bug nelle simulazioni o nel sito
- link non funzionanti o crediti mancanti

Descrivi il problema e, se puoi, indica la pagina e una fonte. Le correzioni le farò io, citando la segnalazione nel commit.

Le pull request aperte verranno chiuse con un rimando a questo file, senza nulla di personale.
